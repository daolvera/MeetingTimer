# Meeting Timer - Angular Frontend Application

A modern Angular 18 application for managing meeting events with built-in timer functionality. This frontend-only application helps you organize speakers, track talk durations, and manage meeting schedules with an intuitive interface.

## Event Functionality

- **Real-time Countdown**: Visual countdown timer for each talk
- **Multiple Time Warnings**: Configure warning messages at different time intervals
- **Last Call Alerts**: Set final warning messages before time expires
- **Play/Pause Controls**: Start, stop, and reset timer functionality
- **Overflow Timing**: Continue timing even after allocated time expires
- **Navigation Controls**: Move between talks within an event

## Installation

1. Clone the repository
2. Navigate to the MeetingTimer directory
3. Install dependencies:

   ```bash
   npm install
   ```
